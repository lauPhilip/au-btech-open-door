# Contributing to Open Door

Thank you for helping. Open Door is at the concept stage, so the most useful contributions right now are ideas and feedback: a scenario you would like to teach, a company type that is missing, or a reaction from students who tried a prototype. Please open an issue and describe it in a few sentences.

When development starts, code changes go through pull requests against the `main` branch. Each pull request should do one thing, describe why in plain words, and pass the automated checks described in the [roadmap](docs/roadmap.md). Scenario texts are written in plain English with short sentences, because many players read English as a second language.

By contributing, you agree that code you add is released under the MIT licence and content you add is released under CC BY-SA 4.0, as described in the [README](README.md). Please do not add real company names, real people or real security weaknesses to scenarios without written permission.
