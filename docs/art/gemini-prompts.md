# Image prompts for Gemini

This page holds ready-to-paste prompts for generating the artwork of the Nordknit office: one prompt for the whole-office map, one prompt for the room picture of each of the nine rooms, and one prompt for a drone view of the company from the outside. Gemini does not remember anything between chats, so every prompt repeats the same style paragraph; paste one prompt per image and keep the aspect ratio exactly as stated, because the app places the pictures behind the walking area and the doors.

## How the pictures are used

The map picture sits behind the clickable room outlines on the teacher's projector and on the student's overview, so it must show the same nine rooms in the same positions, but with no text. The room pictures fill the room view, which is a wide 16:9 side-on scene. The floor is the lower part of the picture, because the student's character walks along it, and the doors are drawn by the app on the left and right edges, so the artwork should not contain doors on those edges or any object close to the edge that would be hidden behind a door. The things that students investigate are drawn by the app as small clickable props, so the room pictures show the furniture and atmosphere, and each prompt only mentions the key objects so the picture hints at them without hiding them.

## The shared style

All prompts begin with this paragraph. If you change the look, change it here and in every prompt.

```
Style: warm, friendly flat vector illustration with soft shading, like a modern editorial or board-game illustration. Clean shapes, gentle rounded corners, subtle paper-like grain, soft ambient shadows, no outlines thicker than a hairline. Calm Scandinavian palette: warm cream #FBF3E6, deep navy ink #1C2430, cobalt blue #2E5BDB as the main accent, sunny yellow #FFE27A for small highlights, coral #E8573F used sparingly for anything risky, and leaf green #2F9E6E for anything safe. Light comes from the upper left. The mood is a real, slightly worn Danish family clothing company, not a glossy corporate office. No text, no letters, no numbers, no logos, no watermarks anywhere in the image, because labels are added by the app. No people in the picture.
```
