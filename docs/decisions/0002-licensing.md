# 0002 · Licensing

**Status:** proposed · **Date:** 2026-10-16

## Context

Open Door should be open source so other teachers and universities can use, adapt and improve it. Its learning content builds on the CyPro material in the Digital Business Development toolbox, which is published under Creative Commons Attribution-ShareAlike 4.0 (CC BY-SA 4.0). That licence allows reuse and adaptation, but anything built on the material must give credit and be shared under the same licence. Some CyPro videos are published under a stricter licence (CC BY-NC-ND) and can only be linked to, not reused or edited.

## Decision

The repository uses two licences. **Code** is released under the MIT licence, which is short, widely understood and lets anyone reuse it freely. **Content** — scenario texts, illustrations, the concept book and teaching material — is released under CC BY-SA 4.0, which matches the CyPro material it adapts.

| Part of the repository | Licence | File |
|---|---|---|
| Source code, tests, build scripts | MIT | `LICENSE` |
| Scenarios, texts, illustrations, docs, teaching material | CC BY-SA 4.0 | `LICENSE-CONTENT.md` |

## What follows

Every scenario and teaching document credits CyPro. CyPro videos are linked, never embedded as edited copies. Real companies are only used as inspiration; scenarios use fictional names and invented weak spots unless a company has agreed to be named. Before the first public release, the copyright holder named in `LICENSE` should be confirmed with Aarhus University, since the work is done in a university role.
